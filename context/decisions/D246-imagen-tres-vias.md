# D246 · UI · La subida de imagen acepta explorador, arrastrar y soltar, y pegar, con una sola validación · Implemented

**Decision:** la zona de `ImageUpload` (estados `vacia` y `error`) recibe el archivo por tres vías: clic/Enter/Espacio (explorador), arrastrar y soltar sobre la zona y Ctrl/Cmd+V con la zona enfocada. Las tres llaman a la misma función (`acceptFile`: `validateImage` → `compressImage` → `onSelect`/`onReject`), así que el tipo, el peso y los mensajes de error son idénticos. La lógica de extraer el archivo (`archivoDeEntrada`: `files` o `items` del portapapeles; prefiere el primer JPG/PNG, si no el primero para que `validateImage` avise del tipo) vive en `lib/image-entrada.ts` con pruebas. Arrastrando archivos la zona muestra borde sólido, fondo de acento y el texto «Suelta la imagen aquí» (no solo color), y el `<output role="status">` lo anuncia. Solo se reacciona a arrastres con `Files`. Texto de ayuda: «Arrastra, pega o busca una imagen» (provisional). Una sola imagen: no se implementó `multiple`.
**Why:** pedido 28 de César; el alumno suele tener la captura en el portapapeles o el archivo en otra ventana.
**Discarded alternative:** soltar también sobre el estado `lista` para reemplazar — la imagen ya elegida se cambia con «Cambiar imagen»; soltar sobre ella se prestaría a reemplazos sin querer.
