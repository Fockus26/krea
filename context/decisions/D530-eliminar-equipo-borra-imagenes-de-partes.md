# D530 · Data · Eliminar equipo borra de B2 las imágenes de sus partes que ya no usa ninguna entrega · Implemented

**Decision:** `borrarPartesDeEquipo` devuelve las rutas de imagen de las partes que borra (como `borrarPartesDeEntrega`). `eliminarEquipoEnTransaccion` lee, con el mismo `UPDATE … RETURNING` que pone `titularNombre`, las respuestas de las entregas grupales del equipo (que se quedan, D307) y descuenta con `rutasSinUso` toda ruta que alguna nombre: una parte aceptada comparte la imagen con la respuesta enviada del capitán. Las demás vuelven en `imagenes` y `borrarUnEquipo` las borra de B2 tras el commit, junto al logo; si B2 falla, se registra y quedan huérfanas (D229). La comparación busca la ruta completa en el JSON de la fila, también en una fila que no valida: ante la duda, la imagen se queda.
**Why:** al eliminar un equipo, las imágenes de las partes entregadas, devueltas o sin enviar quedaban en B2 sin dueño (backlog L52); eliminar entrega y tarea ya las borraban.
**Discarded alternative:** borrar todas las rutas de las partes — rompe la imagen de una pregunta aceptada en una entrega que se queda con su nota. Validar las respuestas con `zRespuesta` y sacar solo sus rutas — una fila que no valida dejaría borrar una imagen que aún se muestra.
