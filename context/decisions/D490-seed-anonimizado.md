# D490 — El seed del repo es anónimo; los datos reales de los alumnos viven fuera de git

**Decision:** `data/seed/*.json` es una copia anonimizada del Excel: cada cédula (alumnos y las dos de profesores que salían en pruebas y documentos) y cada nombre o apellido real se cambió por uno ficticio. El cambio es igual en todo el repo, así que demo, pruebas, canvas, prototipo y decisiones siguen siendo coherentes entre sí. Conserva el orden alfabético de nombres y apellidos, el numérico de las cédulas (`45xxxxxx`, fuera del rango real) y el género del nombre de pila. Los datos reales van a `data/privado/` (gitignored): `import-excel.py` escribe ahí por defecto, y `importar-alumnos.ts` e `importar-tarea-historica.ts`, que cargan producción, leen de ahí. `seed-db.ts` (krea_dev / QA) usa el seed anónimo. El mapa real → ficticio y el script quedan en `data/privado/` (`mapa-anonimo.json`, `anonimizar.py`).
**Why:** César pasó el repo a público (2026-11-20) y `data/seed/alumnos.json` publicaba nombres y cédulas de alumnos menores de edad.
**Pending:** el historial de git y la rama `context-state` siguen teniendo los datos reales. Borrarlos exige reescribir el historial (force-push, prohibido por CLAUDE.md) o volver el repo privado: lo decide César.
