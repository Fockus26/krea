# D148 · Pages · `/profe/evaluar` redirige a la primera entrega de `COLA` y el Panel usa los ids de `COLA` · Implemented

**Decision:** `/profe/evaluar` hace `redirect` a `/profe/evaluar/[id de COLA[0]]` y, si `COLA` está vacía, muestra un estado vacío (`EmptyState` en `Card`). `/profe/evaluar/[entrega]` tiene una página por entrega de `COLA` (`generateStaticParams`), `notFound()` si el id no existe, Anterior/Saltar con enlaces reales por `vecinos()` y «Guardar» de la última vuelve a `/profe/evaluar`. `ENTREGAS_PANEL` (`lib/demo/panel.ts`) se deriva de `COLA` (mismos ids, orden y fechas), así cada «Evaluar» del Panel tiene página. El Toaster es el global del layout (D131): la página no monta uno. `check:paginas` reconoce las rutas que solo redirigen (cascarón `NEXT_REDIRECT` del build) y comprueba que su destino sea una página generada.
**Why:** una sola fuente para la cola evita ids que no casan; el estado de una entrega es un dato, no una ruta.
**Discarded alternative:** mantener ids propios del Panel con una tabla de equivalencias — duplica datos y se desincroniza. Que `/profe/evaluar` sea una lista de la cola — el brief la define como redirect a la primera.
