# D319 · Components · Pantalla «Años y secciones» en `/profe/secciones`, solo para el profesor admin · Implemented

**Decision:** ítem de navegación `secciones` («Años y secciones», ícono `School`) tras Profesores en la lateral y el Menú, `soloAdmin` (D231); la página carga con `pantallaSecciones()` (exige admin: un profe que no lo es vuelve al Panel) y cada Server Action de `lib/acciones/secciones.ts` llama `exigirAdmin()`. Una tarjeta por año (`nombreAnio`: «5.º año», con el uso sumado) y dentro sus secciones (código + «Tiene 12 alumnos, 3 equipos y 2 tareas»). Acciones: «Nuevo año» (número libre 1–9 + letras escritas, pueden ser ninguna), por año «Agregar sección» (letra libre), «Editar» (número) y «Eliminar»; por sección «Editar» (letra) y «Eliminar». Un solo diálogo para toda la pantalla, fuera de las tarjetas: al renombrar o eliminar, la tarjeta o la fila se va con el `refresh()` y el foco vuelve al botón que lo abrió o, si ya no está, a «Agregar sección» del año o a «Nuevo año».
**Why:** es la estructura de toda la escuela (como las cuentas de los profes, D233): un profe cualquiera no debería poder quitar un año. El diálogo único evita que se desmonte con la fila que lo abrió.
**Discarded alternative:** abierta a todo profe (riesgo de borrar estructura sin querer); un diálogo por fila como Profesores (se desmonta con el refresh al renombrar y el foco se pierde); casillas A–Z para las letras iniciales (26 controles en 320 px) en vez de un campo de texto validado.
