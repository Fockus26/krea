**Decision:** `lib/demo/ajustes.ts` exporta `DemoAjuste = { id; destino: { tipo: "alumno"; cedula } | { tipo: "equipo"; id }; valor; motivo; fecha }` y `AJUSTES` con los 4 del lienzo (+2, −1, +1, −1; el de 5C-G1 trae solo fecha, sin hora inventada). `fecha` es ISO local sin zona ("aaaa-mm-ddThh:mm" o "aaaa-mm-dd"), y `fechaAjusteTexto` la formatea sin `Date` (no depende del huso del servidor). `lib/demo/panel.ts` guarda las 7 entregas (4 individuales · 3 grupales; la 1.ª, 5A-G2 Repostería por Yeilin el 25/10/2026 4:12 p. m., y la 2.ª, Jorge Quintero, como fija el brief; las dos últimas son estudiantes de 5C del seed para que el filtro tenga qué filtrar).
