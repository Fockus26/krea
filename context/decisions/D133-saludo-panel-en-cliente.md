# D133 · Pages · Saludo del Panel por la hora del visitante: `useSyncExternalStore` con la hora de la mañana en el servidor · Implemented

**Decision:** `/profe` monta `PanelConHora` (`components/sections/profe-panel/panel-con-hora.tsx`, cliente), que pasa a `PanelView` `saludoTexto(hora)` con `hora = useSyncExternalStore(suscribir, () => new Date().getHours(), () => HORA_SALUDO_SERVIDOR)`. El HTML del servidor y la hidratación dicen «Buenos días, profe» (`HORA_SALUDO_SERVIDOR = 9` en `lib/panel.ts`); justo después React pinta el saludo de la hora local, y un intervalo de un minuto lo cambia si la página queda abierta.
**Why:** D098: con `cacheComponents` el prerender no puede leer el reloj. `useSyncExternalStore` con instantánea de servidor distinta es la vía de React para un valor solo del cliente sin error de hidratación, y no necesita `useEffect` + `setState`. El texto de la mañana es copy del lienzo (no se inventa uno neutro).
**Discarded alternative:** saludo neutro en el servidor («Hola, profe») — copy nuevo sin respaldo del handoff. `useEffect` con `setState` — un render extra igual y el patrón que la regla de React desaconseja. Leer la hora en el servidor con `connection()` — la página dejaría de ser estática solo por el saludo.
