# D050 · Ranking · RankRow/RankDelta: una sola fila para estudiante y equipo, `<li>` con nombre accesible · Implemented

**Decision:** `RankRow` recibe `RankingPuesto` plano (`puesto`, `empate`, `enRiesgo`, de `rankCompetition`) + `nombre`, `puntos`, `subtitulo?`, `media: ReactNode` (un `UserAvatar` o un `TeamLogo` de 40), `delta?`, `esTu?`, `moving?`, `efecto?`. El tipo de fila sale de `rankRowKind` (`lib/rank-row.ts`): **riesgo gana a top 10** (con ≤ 10 alumnos las últimas filas se ven apagadas), top = puesto ≤ 10, normal el resto; `esTu` se combina con cualquiera (fondo `--accent-soft`, borde interior 2 px con `outline` inset —no pisa el `box-shadow`—, chip «tú» `Badge tu`). El chip «Empate» (solo top 10, `mostrarChipEmpate`) **ocupa la columna del delta**, como en `Ranking.dc.html`. En riesgo, el gris y el `.75` van solo al `<img>` (`[&_img]:grayscale [&_img]:opacity-75` en el contenedor del medio). El `<li>` lleva `aria-label` = «Puesto 4, María Méndez, 30,5 puntos, subió 2 puestos» (+ «, empatado» si se ve el chip, + «, eres tú») y la caja visual interior va `aria-hidden`: el lector dice la fila una sola vez. El subtítulo (equipo / capitán) no entra en el nombre, como el ejemplo del handoff. `RankDelta`: chip 22 con flecha + número (o «=»), texto accesible `deltaTexto` («subió 2 puestos», «bajó 1 puesto», «sin cambios»), fondos `bg-chip-ok`/`bg-chip-err`.
**Why:** el handoff pide un solo componente `RankRow` para ambas listas (§2.9 y §3 equipos) y un nombre accesible por `<li>`; con `aria-hidden` en el contenido no hay doble lectura. El `<li>` queda como objeto del FLIP (translateY) y la caja interior recibe elevación, brillo y temblor, así no compiten por `transform` (D053).
**Discarded alternative:** dos variantes (`StudentRow`/`TeamRow`) — duplican 90 % del código; `aria-label` sobre el contenido visible sin `aria-hidden` — doble lectura. Riesgo: algunos lectores en modo exploración leen el `aria-label` del `<li>`; es el patrón que pide el handoff. Si una fila pasa a ser enlace, el nombre accesible debe moverse al enlace.
