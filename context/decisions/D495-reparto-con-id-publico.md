# D495 · Data · Reparto de partes: los integrantes van por id público y el servidor lo traduce a la cédula al asignar · Implemented

**Decision:** `repartoVista` (capitán) manda `integrantes: { id, nombre }` y `filas[].asignado` con el id público (`EntradaReparto.idDe`); el `Select` de `RepartoPanel` usa ese id como valor. `zAsignarParte.asignado` es `zIdPublico.nullable()`. `accionParteEnTransaccion(…, idDe)` lee los integrantes actuales del equipo dentro de la transacción y traduce con `cedulaDeId`: un id que no es de ninguno de ellos (la cédula misma, el de otro equipo, uno inventado o de otro secreto) es `integrante`, como asignar a quien no está en el equipo. «La respondo yo», aceptar, devolver y entregar no llevan id (la cédula sale de la sesión). La base sigue guardando la cédula en `partes.asignado`.
**Why:** el capitán recibía la cédula de cada compañero en las opciones del `Select` (RSC payload). Traducir contra los miembros leídos en la transacción mantiene la regla de D417: solo se asigna a integrantes actuales.
**Discarded alternative:** mandar el índice del integrante en la lista (frágil si el equipo cambia entre la carga y el clic) · traducir en la Server Action con una lectura aparte (fuera de la transacción).
