# D425 · Data · % orientativo de IA con la API de Claude (Haiku 5.5) y tabla `analisis_ia` · Implemented

**Decision:** el % de probabilidad de uso de IA de una respuesta de texto lo estima la API de Claude con el SDK oficial (`@anthropic-ai/sdk`), modelo `claude-haiku-5-5` en la constante `MODELO_IA` (`lib/ia/peticion.ts`). Petición mínima: `thinking: disabled`, `effort: low`, `max_tokens: 64`, salida estructurada (`output_config.format` con un objeto `{ porcentaje: integer }`), sin explicación. Viaja **solo el texto** (nunca nombre, cédula, tarea ni sección). Se guarda en la tabla nueva `analisis_ia` (PK `entrega_id` + `pregunta_id`; `porcentaje`, `huella`, `modelo`, `autor_id`, `analizado_en` en ms): uno por respuesta, el nuevo sobrescribe. Sin claves foráneas ni cascada: quien lee tolera filas de entregas que ya no existen (limpieza pendiente).
**Why:** pedido de César (E1, ronda 2026-11-14): API de Claude con saldo en Console y un modelo barato; solo la estimación. Guardarla evita pagar dos veces lo mismo y deja que otro profe la vea.
**Discarded alternative:** un detector dedicado de terceros — otro proveedor, otra clave y otro contrato de datos para un experimento; pedir también una explicación — César la descartó y multiplica el costo de salida.
