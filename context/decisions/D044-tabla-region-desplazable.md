# D044 · Components · Table: contenedor `<section>` desplazable con nombre obligatorio, enfocable y `position: relative`; `th` sticky y pista bajo 1024 · Implemented

**Decision:** `Table` exige `label` (se vuelve `aria-label` del contenedor `<section tabIndex={0}>`, rol implícito `region` al tener nombre). El contenedor lleva `relative overflow-x-auto`, radio 16, `--surface`, `shadow-1` (en oscuro borde en vez de sombra) y anillo de foco; la tabla `min-w-190` (760 px), `border-separate` para que el borde del `th` sticky no se pierda. `TableHead` 44 px, `text-eyebrow` con `tracking-[0.06em]`, `sticky top-0 z-table-head`; `TableCell` 60 px, padding 8 12 (16 en los extremos). `numeric` en cabecera y celda = `nums text-right`. La pista "Desliza la tabla para ver más columnas" (ícono `MoveHorizontal`) sale bajo la tabla con `lg:hidden`; se apaga con `hint={false}`. Se quita `TableFooter` y el `"use client"` del crudo.
**Why:** HANDOFF §2.15 y §8 (un `sr-only` dentro de un contenedor con scroll necesita `position: relative`). `<section>` en vez de `div role="region"` porque Biome (`useSemanticElements`) lo exige y es el mismo rol.
**Discarded alternative:** envolver el scroll en `overflow-y` para que el `th` pegue a la ventana — rompería el scroll de página; sticky respecto al contenedor es suficiente.
