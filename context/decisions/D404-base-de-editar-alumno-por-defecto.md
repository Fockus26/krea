# D404 · Grading · La base de «Editar alumno» es la base por defecto de sus próximas evaluaciones · Implemented

**Decision:** elegir la base al evaluar NO cambia `usuarios.base`. La base de «Editar alumno» queda como la base con la que empiezan sus próximas evaluaciones (y el respaldo de las evaluaciones que no guardaron la suya, D403); cambiarla no mueve las tareas ya evaluadas desde la app. El historial de cambios de base (D176) sigue igual, con su motivo obligatorio. La ayuda del campo pasa a decir: «Es la base con la que empiezan sus próximas evaluaciones; las tareas ya evaluadas conservan la suya.» (CONTENT_CHECKLIST fila 214). El chip «Base N» del Perfil del alumno sigue mostrando su base actual (pendiente de César: ver el PR).
**Why:** enfoque decidido en la orquestación (punto 4 del prompt W1): una base elegida para una tarea es una excepción de esa tarea; si actualizara la de «Editar alumno», el profe cambiaría sin querer la base de las siguientes y el historial perdería su motivo.
**Discarded alternative:** que elegir una base distinta al evaluar actualice también la base por defecto (`usuarios.base` + fila de historial con un motivo automático): las siguientes tareas heredarían una excepción y el historial se llenaría de cambios sin motivo escrito.
